UNIT 3 – ARRAYS AND STRINGS

1. A Simple Program Using Array

Definition: An array is a collection of elements of the same data type stored under one common name.

Explanation

An array allows us to store multiple values using a single variable name. Instead of declaring many separate variables, we can declare one array. Each element of an array is accessed using its index.

In C, array indexing starts from 0. Therefore, if an array contains 5 elements, its indexes are: 0, 1, 2, 3 and 4.

Syntax: 
data_type array_name[size];
Example: 
int marks[5];

Here, int is the data type, marks is the array name, and 5 represents the number of elements.

2. Array Initialization

Definition: Array initialization means assigning initial values to the elements of an array when the array is declared.
Syntax: 
data_type array_name[size] = {value1, value2, value3};
Example: 
int marks[5] = {80, 75, 90, 85, 70};

Explanation

The values are stored according to their indexes:

Index Value
080
175
290
385
470
Important Points:
  • Array indexing starts from 0.
  • All elements normally have the same data type.
  • The size determines the number of elements.
  • Accessing an index outside the array can cause undefined behaviour.

3. One-Dimensional Array

Definition: A one-dimensional array is an array in which elements are arranged in a single sequence.
Syntax: 
data_type array_name[size];
Example: 
int numbers[5] = {10,20,30,40,50};

printf("%d", numbers[2]);

The output is 30 because index 2 contains 30.

4. Two-Dimensional Arrays

Definition: A two-dimensional array is an array arranged in rows and columns. It is commonly used to represent tables and matrices.
Syntax: 
data_type array_name[rows][columns];
Example: 
int a[2][3];

This creates an array containing 2 rows and 3 columns.

Column 0 Column 1 Column 2
Row 0 a[0][0] a[0][1] a[0][2]
Row 1 a[1][0] a[1][1] a[1][2]

5. Initializing a Two-Dimensional Array

Syntax: 
int matrix[2][3] = {
    {1,2,3},
    {4,5,6}
};
Example: 
#include <stdio.h>

int main()
{
    int a[2][3] = {
        {1,2,3},
        {4,5,6}
    };

    printf("%d\n", a[0][1]);
    printf("%d\n", a[1][2]);

    return 0;
}
Output: 
2
6

6. Memory Map of a Two-Dimensional Array

Definition: A memory map shows how array elements are arranged in memory.

C stores two-dimensional arrays in row-major order. This means that the first row is stored completely before the second row.

Example: 
int a[2][3] = {
    {10,20,30},
    {40,50,60}
};

Conceptually the memory order is: 

10 → 20 → 30 → 40 → 50 → 60

7. Row-Major Order

Definition: Row-major order is the method of storing a two-dimensional array row by row in consecutive memory locations. 
int a[2][2] = {
    {1,2},
    {3,4}
};

Memory order: 

1 → 2 → 3 → 4

8. Strings in C

Definition: A string in C is a sequence of characters terminated by the null character '\0'.

C does not have a separate built-in string data type. Strings are stored using character arrays.

Syntax: 
char string_name[size];
char name[20] = "Rahul";

Internally, the string is stored as: 

R a h u l \0

9. String Initialization

Method 1: 
char name[10] = "Hello";
Method 2: 
char name[] = "Hello";
Method 3: 
char name[6] = {'H','e','l','l','o','\0'};
Important: A string must have enough space for its characters plus the terminating null character.

10. Standard Library String Functions

Definition: String library functions are predefined functions provided by C for performing common operations on strings.

The functions are declared in: 

#include <string.h>

Important functions in this syllabus are:

  • strlen()
  • strcpy()
  • strcat()
  • strcmp()

Definition: strcmp() compares two strings lexicographically.

The result is:

UNIT 4 – FUNCTIONS AND POINTERS

1. Function

Definition: A function is a self-contained block of C statements designed to perform a particular task.

Functions make programs easier to understand, test and maintain.

General Syntax: 
return_type function_name(parameter_list)
{
    statements;
}
int add(int a, int b)
{
    return a + b;
}

2. Function Declaration

Definition: A function declaration tells the compiler about the function name, return type and parameters before the function is used. 
return_type function_name(parameter_list);
int add(int, int);

3. Function Definition

Definition: A function definition contains the actual statements that perform the task of the function. 
int add(int a, int b)
{
    return a + b;
}

4. Function Call

Definition: A function call is a statement that transfers control to a function so that its statements can be executed. 
result = add(10,20);

5. Passing Values Between Functions

Data can be passed to a function using parameters and arguments. 

#include <stdio.h>

int add(int a, int b)
{
    return a + b;
}

int main()
{
    int result;

    result = add(10,20);

    printf("Sum = %d", result);

    return 0;
}
Output: 
Sum = 30

6. Scope Rule of Functions

Definition: Scope refers to the region of a program where an identifier such as a variable or function can be accessed.

Local Scope

A variable declared inside a function is generally accessible only within that function.

Global Scope

A variable declared outside functions can generally be accessed by functions in the same source file, subject to normal C scope rules. 

#include <stdio.h>

int x = 100;

void display()
{
    printf("%d", x);
}

int main()
{
    display();

    return 0;
}

7. Calling Convention

Definition: Calling convention refers to the rules used when a function is called, including how arguments are passed and how a return value is handled.

In C, arguments are normally passed by value. When pointer arguments are used, the called function can access and modify the caller's objects through those pointers.

8. Return Type of Function

Definition: The return type specifies the type of value a function returns to the calling function. 
int add(int a, int b)
{
    return a + b;
}

The return type is int.

A function that does not return a value can use: 

void display()
{
    printf("Hello");
}

9. Call by Value

Definition: In call by value, a function receives copies of the argument values. 
void change(int x)
{
    x = 100;
}

Changing x inside the function does not change the original variable in the caller.

10. Call by Reference

Definition: In traditional C terminology, "call by reference" commonly refers to passing the address of an object to a function using a pointer so the function can modify the original object.
Important C fact: C itself uses pass-by-value. When a pointer is passed, the pointer value is copied, but both the caller and callee can use that pointer to access the same object. 
void function(int *x)
{
    *x = 100;
}

11. Recursion

Definition: Recursion is a process in which a function calls itself until a terminating condition is reached. 
return_type function()
{
    if(condition)
        return value;

    return function();
}
Factorial using recursion: 
int factorial(int n)
{
    if(n == 0)
        return 1;

    return n * factorial(n - 1);
}
A recursive function must have a proper base condition; otherwise, recursive calls may continue indefinitely.

12. Introduction to Pointers

Definition: A pointer is a variable that stores the memory address of another variable. 
data_type *pointer_name;
int *p;

13. Pointer Declaration

int *p;
float *q;
char *r;

The type indicates the type of object that the pointer is intended to point to.

14. Pointer Initialization

int number = 50;
int *ptr = &number;

Here, ptr contains the address of number.

15. Address Operator &

Definition: The address operator & produces the address of an object. 
int x = 10;

printf("%p", (void *)&x);

16. Dereference Operator *

Definition: The dereference operator * is used with a pointer expression to access the object stored at the pointed-to address. 
int x = 10;
int *p = &x;

printf("%d", *p);
Output: 
10

17. Pointer Notation

Pointers use two important forms:

Expression Meaning
&x Address of x
*p Value of the object pointed to by p

18. Pointers and Functions

Pointers can be passed to functions when a function needs access to an object in the caller. 

#include <stdio.h>

void change(int *x)
{
    *x = 100;
}

int main()
{
    int a = 10;

    change(&a);

    printf("%d", a);

    return 0;
}
Output: 
100

19. Types of Functions

Definition: Functions in C can be classified based on whether they accept arguments and whether they return a value.
Type Arguments Return Value
Type 1 No arguments No return value
Type 2 Arguments No return value
Type 3 No arguments Returns a value
Type 4 Arguments Returns a value

Example – Arguments and Return Value

int add(int a, int b)
{
    return a + b;
}

20. Library Functions

Definition: Library functions are predefined functions supplied by the C standard library.

Examples include:

  • printf() – formatted output
  • scanf() – formatted input
  • strlen() – string length
  • strcpy() – copy string
  • strcat() – concatenate strings
  • strcmp() – compare strings
  • sqrt() – square root
  • pow() – power calculation
The appropriate header file must be included before using a library function.

21. User-Defined Functions

Definition: A user-defined function is a function created by the programmer to perform a particular task. 
return_type function_name(parameters)
{
    statements;
}
int square(int n)
{
    return n * n;
}

The function is created by the programmer rather than supplied as a standard library function.

UNIT 5 – MACROS, STRUCTURES AND FILES

1. Introduction to Macros

Definition: A macro is a symbolic name or parameterized expression defined using the C preprocessor.

Macros are processed before the actual compilation stage.

2. #define

Definition: #define is a preprocessor directive used to define macros. 
#define NAME value
#define PI 3.14159

Whenever the macro name is used, the preprocessor substitutes its replacement text according to macro rules.

3. Parameterized Macros

Definition: A parameterized macro is a macro that accepts arguments. 
#define MACRO(parameter) expression
#define SQUARE(x) ((x) * (x))

Parentheses are important in parameterized macros to avoid many operator-precedence problems.

4. Structures

Definition: A structure is a user-defined data type that groups related variables, possibly of different data types, under one name.

For example, student information may contain:

  • Roll number – int
  • Name – character array
  • Marks – float

5. Declaring a Structure

struct structure_name
{
    data_type member1;
    data_type member2;
};
struct Student
{
    int roll;
    char name[30];
    float marks;
};

6. Structure Members

The variables declared inside a structure are called structure members. 

struct Student
{
    int roll;
    char name[30];
    float marks;
};

Here, roll, name and marks are structure members.

7. Accessing Structure Elements

Structure members are normally accessed using the dot operator. 
structure_variable.member;
struct Student s;

s.roll = 10;
s.marks = 85.5;

8. Storing Structure Elements

#include <stdio.h>

struct Student
{
    int roll;
    char name[30];
    float marks;
};

int main()
{
    struct Student s;

    s.roll = 1;

    printf("Enter name: ");
    scanf("%29s", s.name);

    printf("Enter marks: ");
    scanf("%f", &s.marks);

    printf("\nRoll = %d", s.roll);
    printf("\nName = %s", s.name);
    printf("\nMarks = %.2f", s.marks);

    return 0;
}

9. Array of Structures

Definition: An array of structures is an array whose elements are structure variables of the same structure type. 
struct Student students[50];
struct Student
{
    int roll;
    char name[30];
};

struct Student students[3];

10. Unions

Definition: A union is a user-defined type in which all members share the same memory location. 
union union_name
{
    data_type member1;
    data_type member2;
};
union Data
{
    int i;
    float f;
    char ch;
};

11. Structure vs Union

Structure Union
Members have separate storage within the structure object. Members share the same storage.
Multiple members can hold values at the same time. Typically only one member's stored value is intended to be used at a time.
Size is related to the storage required for all members plus possible padding. Size is based on the largest member, subject to alignment requirements.

12. Introduction to Files

Definition: A file is a named collection of data stored on secondary storage so that information can be retained after a program finishes execution.

C provides file-handling functions through the standard I/O library.

The main file pointer type is: 

FILE *

13. File Opening Modes

Mode Purpose
r Open an existing file for reading.
w Open for writing; creates a new file or truncates an existing file.
a Open for appending; writes occur at the end.
r+ Open an existing file for reading and writing.
w+ Open for reading and writing; creates/truncates the file.
a+ Open for reading and appending.

14. fopen()

Definition: fopen() opens a file and associates it with a FILE stream. 
FILE *fp;

fp = fopen("filename", "mode");
FILE *fp;

fp = fopen("data.txt", "w");

if(fp == NULL)
{
    printf("File could not be opened");
}

15. fclose()

Definition: fclose() closes an opened file stream. 
fclose(file_pointer);
fclose(fp);

16. Writing to Files

Writing means storing information into a file.

The file should normally be opened in a mode that permits writing. 

FILE *fp;

fp = fopen("data.txt", "w");

if(fp != NULL)
{
    fprintf(fp, "Hello C Programming");
    fclose(fp);
}

17. Reading from Files

Reading means retrieving data that has previously been stored in a file. 

FILE *fp;
char word[50];

fp = fopen("data.txt", "r");

if(fp != NULL)
{
    fscanf(fp, "%49s", word);
    printf("%s", word);
    fclose(fp);
}

18. fprintf()

Definition: fprintf() writes formatted data to a file stream. 
fprintf(file_pointer, "format", values);
fprintf(fp, "Age = %d", age);

19. fscanf()

Definition: fscanf() reads formatted data from a file stream. 
fscanf(file_pointer, "format", &variables);
fscanf(fp, "%d", &number);

20. getw()

Definition: getw() is an older, non-standard extension found in some C environments for reading an integer from a stream. It is not part of the ISO C standard. 
getw(file_pointer);
For portable modern C programming, prefer standard functions such as fscanf(), fread(), or other appropriate standard I/O functions.

21. putw()

Definition: putw() is an older, non-standard extension found in some C environments for writing an integer to a stream. It is not part of the ISO C standard. 
putw(integer, file_pointer);
As with getw(), portable C programs should generally use standard ISO C file functions instead.

Program 6 – Palindrome Using Function

Aim

To check whether a number is a palindrome using a user-defined function.

Algorithm

  1. Start.
  2. Read a number.
  3. Pass the number to the palindrome function.
  4. Reverse the number inside the function.
  5. Compare the reversed number with the original.
  6. Return the result.
  7. Display whether the number is palindrome or not.
  8. Stop.

Program Code

#include <stdio.h>

int palindrome(int n)
{
    int original = n;
    int reverse = 0;
    int digit;

    while(n != 0)
    {
        digit = n % 10;
        reverse = reverse * 10 + digit;
        n = n / 10;
    }

    return original == reverse;
}

int main()
{
    int n;

    printf("Enter a number: ");
    scanf("%d", &n);

    if(palindrome(n))
        printf("Palindrome number");
    else
        printf("Not a palindrome number");

    return 0;
}

Sample Output

Enter a number: 121
Palindrome number

Program 7 – Armstrong Number Using Function

Aim

To check whether a three-digit number is an Armstrong number using a function.

Algorithm

  1. Start.
  2. Read a three-digit number.
  3. Pass the number to the function.
  4. Extract each digit.
  5. Calculate the sum of cubes of the digits.
  6. Compare the sum with the original number.
  7. Display the result.
  8. Stop.

Program Code

#include <stdio.h>

int isArmstrong(int n)
{
    int original = n;
    int sum = 0;
    int digit;

    while(n != 0)
    {
        digit = n % 10;
        sum = sum + digit * digit * digit;
        n = n / 10;
    }

    return sum == original;
}

int main()
{
    int n;

    printf("Enter a three-digit number: ");
    scanf("%d", &n);

    if(isArmstrong(n))
        printf("Armstrong number");
    else
        printf("Not an Armstrong number");

    return 0;
}

Sample Output

Enter a three-digit number: 153
Armstrong number

Program 8 – Prime Number Using Function

Aim

To check whether a number is prime using a user-defined function.

Algorithm

  1. Start.
  2. Read a number.
  3. Pass it to the prime-checking function.
  4. Check possible divisors.
  5. Return whether the number is prime.
  6. Display the result.
  7. Stop.

Program Code

#include <stdio.h>

int isPrime(int n)
{
    int i;

    if(n < 2)
        return 0;

    for(i = 2; i <= n / i; i++)
    {
        if(n % i == 0)
            return 0;
    }

    return 1;
}

int main()
{
    int n;

    printf("Enter a number: ");
    scanf("%d", &n);

    if(isPrime(n))
        printf("Prime number");
    else
        printf("Not a prime number");

    return 0;
}

Sample Output

Enter a number: 17
Prime number

To calculate the factorial of a number using a user-defined function.

Algorithm

10. Explain two-dimensional arrays with syntax and example.
Answer: Syntax: 
int a[rows][columns];
Example: 
int a[2][3] = {
    {1,2,3},
    {4,5,6}
};
It contains 2 rows and 3 columns.
11. Explain call by value and pointer-based modification of caller data.
Answer: In call by value, the function receives a copy of the argument. To modify the caller's object, C can pass its address using a pointer.

Part D – 5 Marks

12. Explain the four common categories of functions based on arguments and return values.
Answer: Functions can be categorized as: 1. No arguments, no return value. 2. Arguments, no return value. 3. No arguments, returns a value. 4. Arguments, returns a value. The fourth category can be represented as: 
int add(int a, int b)
{
    return a + b;
}
13. Explain structures and unions.
Answer: A structure stores its members as separate members within the structure object, while union members share the same storage. A structure can hold values for multiple members at the same time; a union is designed around shared storage.

15. Explain file handling in C with fopen(), fclose(), fprintf() and fscanf().
Answer: File handling allows programs to store and retrieve data from files. fopen() opens a file, fclose() closes it, fprintf() writes formatted data to a stream, and fscanf() reads formatted data from a stream. Example: 
FILE *fp;

fp = fopen("data.txt", "w");

if(fp != NULL)
{
    fprintf(fp, "Hello");
    fclose(fp);
}

16. Explain strings and the functions strlen(), strcpy(), strcat() and strcmp() with examples.
Answer: A string is a null-terminated character sequence. The functions perform length calculation, copying, concatenation and comparison respectively. Examples: 
strlen(str);
strcpy(dest, src);
strcat(dest, src);
strcmp(str1, str2);

Part H – 10 Marks

17. Explain functions and pointers in detail and write suitable examples.
Answer: A function is a reusable block of statements. A pointer stores an address. Functions can receive pointers when they need access to caller-owned objects. Example: 
void change(int *x)
{
    *x = 100;
}
Calling change(&a) allows the function to modify the object a.
